🚀 Zapwarm API

Documentação oficial · v1.0.0

Introdução

API nativa de WhatsApp baseada em Baileys. Suporta múltiplas instâncias, envio de mensagens, gerenciamento de grupos, contatos, status, webhooks e bot de IA integrado.

Base URL: https://api.zapbulk.com.br
Autenticação: Headers instance e token.

Instâncias

POST/instance/create

Cria uma nova instância.

curl -X POST https://api.zapbulk.com.br/instance/create \\
  -H "Content-Type: application/json" \\
  -d '{"instance":"minha_instancia"}'
GET/instance/qrcode

Retorna QR Code em base64.

curl "https://api.zapbulk.com.br/instance/qrcode?instance=X&token=Y"
GET/instance/status

Consulta status da instância.

curl https://api.zapbulk.com.br/instance/status \\
  -H "instance: minha_instancia" -H "token: SEU_TOKEN"
GET/instance/list

Lista todas as instâncias.

curl https://api.zapbulk.com.br/instance/list
DELETE/instance/logout

Desconecta e remove uma instância.

Mensagens

POST/message/send-text

Envia texto.

curl -X POST https://api.zapbulk.com.br/message/send-text \\
  -H "instance: minha_instancia" -H "token: SEU_TOKEN" \\
  -H "Content-Type: application/json" \\
  -d '{"number":"5515999999999","text":"Olá!"}'
POST/message/send-image

Envia imagem (URL ou base64).

POST/message/send-audio

Envia áudio.

POST/message/send-document

Envia documento.

Bot IA

POST/bot/config

Configura o bot ChatGPT.

curl -X POST https://api.zapbulk.com.br/bot/config \\
  -H "instance: minha_instancia" -H "token: SEU_TOKEN" \\
  -H "Content-Type: application/json" \\
  -d '{"active":true,"prompt":"Você é atendente"}'
GET/bot/config

Consulta config do bot.
